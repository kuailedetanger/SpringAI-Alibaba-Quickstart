## 一、Models 大模型（教学增强版）

### 1、是什么

AI 的**大脑**，预先用海量数据训练好的智能模型。

### 2、模型分类

- **对话模型 ChatModel**：聊天、写代码、写文案（GPT、通义千问、Ollama）

- **向量模型 EmbeddingModel**：专门把文字转数字，做知识库

- **图片模型 ImageModel**：文生图、图生图

- **语音模型 AudioModel**：语音转文字

### 3、通俗理解

Spring AI 最大作用：**把所有模型统一接口，一行代码切换模型，不用重写业务。**

### 4、学生必背一句话

**Models就是AI大脑，SpringAI统一封装各类大模型，让开发者无脑切换模型。**

## 二、Prompts 提示词（教学增强版）

### 1、是什么

你发给大模型的**所有内容统称提示词**，不是单纯一句话。

### 2、组成两部分

#### （1）System Prompt 系统提示

设定 AI 身份、规则、语气。

> 示例：你是一名Java后端老师，回答简洁、通俗易懂、用例子说明。
> 
> 

#### （2）User Prompt 用户提示

用户真实的提问、需求。

### 3、正误对比案例

#### ❌ 劣质提示词

提问：什么是向量？（无任何约束，回答晦涩难懂）

#### ✅ 优质提示词

系统：你是零基础授课老师，大白话、不要公式。

用户：什么是向量？

### 4、关键点

AI 本身智商固定，**AI回答好不好，70%靠提示词写得好不好。**

### 5、代码极简示例

```java
//系统提示（定人设）
Prompt system = new SystemPrompt("你是Java老师，通俗简短");
//用户提示（提问题）
Prompt user = new UserPrompt("解释什么是Prompt");

```

### 6、学生必背一句话

**Prompt = 你给 AI 的完整指令 \+ 角色设定 \+ 问题。系统定规则，用户提需求。**

## 三、Prompt Templates 提示词模板（教学增强版）

### 1、是什么

**提示词模板：预留占位符、动态填充、重复复用的提示词。**

官方比喻：等同于 SpringMVC 的 View 视图。

### 2、生活化比喻

请假条模板：尊敬的\{老师\}，我因\{原因\}请假\{天数\}天。

### 3、正误对比

#### ❌ 错误：字符串拼接

```java
String p = "请用"+style+"讲解"+knowledge;

```

#### ✅ 优质：模板写法

```java
String temp = "请用{style}讲解{knowledge}";
PromptTemplate t = new PromptTemplate(temp);
t.apply(Map.of("style","幽默","knowledge","向量"));

```

### 4、优势

干净、无拼接、可复用、易维护、可放配置文件。

### 5、学生必背一句话

**PromptTemplates 就是提示词模板，固定文案留空位、动态传参填数据；杜绝字符串拼接。**

## 四、Embeddings 向量嵌入（教学增强版）

### 1、是什么

**把文字、图片转换成一串数字（浮点数组），给AI识别。**

### 2、核心原理

**语义越相似，向量距离越近；意思不同，距离很远。**

### 3、通俗理解（你的原话修正版）

把文档扔给向量模型 → 生成数字A；

用户换话术提问 → 生成数字B；

A、B数字相近 → AI判定是同一个意思。

### 4、传统搜索 VS 向量搜索

#### ❌ 关键字搜索：必须字一样才能搜到

#### ✅ 向量搜索：意思一样就能搜到

### 5、代码最简示例

```java
//自动注入向量模型
@Autowired
private EmbeddingModel embeddingModel;

//文本转向量
List<Double> vector = embeddingModel.embed("SpringAI真好用");

```

### 6、学生必背一句话

**Embedding给文字生成数字身份证，不靠关键字、靠语义匹配，是RAG知识库底层核心。**

## 五、Tokens 令牌（教学增强版）

### 1、是什么

大模型的**最小计算单位**。

### 2、通俗换算

- 中文：1汉字 ≈ 1\~2 Token

- 英文：1单词 ≈ 1 Token

### 3、三大作用（必考）

1. **计费**：输入\+输出都扣费

2. **长度限制**：上下文窗口，超限截断

3. **性能**：Token越多速度越慢

### 4、通俗比喻

Token = 纸张，纸有限、纸要钱，写多了必须裁剪。

### 5、学生必背一句话

**Token是AI计费和长度单位，控制对话长短、决定花钱多少。**

## 六、Structured Output 结构化输出（教学增强版）

### 1、是什么

**强制AI返回规范格式，自动转为Java实体类，不用手动解析字符串。**

### 2、痛点

默认AI返回纯文本字符串，哪怕要JSON也是乱文本，极易解析失败。

### 3、正误对比

#### ❌ 错误：自己手写JSON解析，极易报错

#### ✅ 优质：SpringAI自动映射实体类

### 4、适用场景

抽取姓名、电话、地址、订单、表单解析。

### 5、学生必背一句话

**结构化输出就是强制AI不乱写，严格返回指定格式，后端直接接收实体类。**

---

## 七、RAG 检索增强生成（教学增强版）

### 1、是什么

**让AI读你的私有文档，不用训练模型，精准回答私有数据。**

### 2、解决三大问题

1. 模型知识过期

2. 不懂私有数据

3. AI幻觉瞎编

### 3、执行流程（必考4步）

1. 文档加载

2. 切片\+向量化

3. 相似度检索

4. 拼接提示词生成答案

### 4、通俗比喻

RAG = 给学霸递课本，让他看着课本答题。

### 5、RAG VS 微调

RAG低成本、不用训练；微调昂贵、难度极大。

### 6、学生必背一句话

**RAG就是给AI看书，检索私有文档，低成本解决知识过期和幻觉问题。**

## 八、Tool Calling 工具调用（教学增强版）

### 1、是什么

**让大模型主动调用你写的Java方法，执行代码。**

### 2、解决什么

AI断网、不能查数据库、不能查实时数据、没有手脚。

### 3、通俗比喻

RAG=看书；Tool=动手。

### 4、执行流程

注册工具→AI判断→AI传参→程序执行→返回结果→AI润色回答。

### 5、最简代码

```java
@Tool(description = "获取当前系统时间")
public String getNowTime(){
    return LocalDateTime.now().toString();
}

```

### 6、学生必背一句话

**ToolCalling给AI安装手脚，自动调用Java代码，查询实时数据、操作业务功能。**

## 九、Evaluation AI 结果评估（教学增强版）

### 1、是什么

**给AI回答自动打分、质检、判断对错。**

### 2、四大评估维度

- 相关性：有没有答非所问

- 正确性：有没有瞎编

- 完整性：有没有漏重点

- 连贯性：语句通顺

### 3、通俗比喻

Evaluation = 阅卷老师，自动批改AI答案。

### 4、代码示例

```java
RelevanceEvaluator evaluator = new RelevanceEvaluator(chatModel);
EvaluationRequest request = EvaluationRequest.builder()
        .userQuery("RAG作用？")
        .modelResponse("读取私有文档，防止幻觉")
        .build();
//自动判断是否合格
evaluator.evaluate(request);

```

### 5、学生必背一句话

**Evaluation自动给AI质检，过滤劣质回答，防止幻觉，是上线必备环节。**
